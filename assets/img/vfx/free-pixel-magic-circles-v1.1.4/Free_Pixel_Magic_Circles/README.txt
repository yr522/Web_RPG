WHAT'S INSIDE
  24 circles across 6 palettes (Arcane, Ember, Frost, Verdant, Void, Radiant):
  19 top-down circles and 5 ground / isometric ovals for floors and pads.
  contact_sheet.png shows them all. CATALOG.txt lists each one's settings.

  Every circle has 4 animations that chain seamlessly:
    charge     12 frames   plays once  (the circle draws itself in)
    idle       16 frames   loops       (rings turn, glyphs pulse)
    activate   10 frames   plays once  (flash + shockwave, ends back on idle)
    dissipate  10 frames   plays once  (fades out)
  All at 12 fps. Charge ends where idle starts, activate starts and ends on the
  first idle frame, and dissipate starts there too, so you can play
  charge -> idle -> activate -> idle -> dissipate with no pops.

  3 sizes per circle:
    top-down circles   32x32, 64x64, 128x128
    ground ovals       64x32, 128x64, 192x96

FILES (circles/NN_name/WxH/)
  *_sheet.png             Sprite sheet. Rows top to bottom: charge, idle,
                          activate, dissipate. Columns are frames; a short row
                          leaves its unused cells transparent.
  *_<anim>_strip.png      One horizontal strip per animation.
  frames/<anim>/NN.png    Every frame as its own PNG.
  *_idle.gif              Idle loop preview (the two larger sizes).
  *_sequence.gif          The full chain preview (the two larger sizes).

  pack.json               Frame size, frame count, row and loop flag for every
                          sheet, for import scripts in any engine.
  circlesmith_presets.json  The settings for all 24 circles, in Circlesmith's
                          preset format.

  Everything is indexed-color PNG with real transparency, no anti-aliasing,
  up to 6 colors (5 light levels plus a dark outline). Scale by whole
  numbers with nearest-neighbor filtering to keep the pixels crisp.

QUICK START
  Godot 4: drop a sheet in your project, set the texture filter to Nearest,
  add an AnimatedSprite2D, create a new SpriteFrames, use "Add frames from
  sprite sheet", set Horizontal = 16 and Vertical = 4, and pick each row as an
  animation.

  Unity: import a sheet, set Sprite Mode to Multiple, Filter Mode to Point and
  Compression to None, then Slice > Grid By Cell Size with the circle size.

  GameMaker / Defold / Love2D / Phaser / anything else: use the strips or the
  per-frame PNGs and the frame counts above (or read pack.json).

  Aseprite: File > Import Sprite Sheet, Type "By Rows", frame size = the
  circle size. Or open the frames folder as a sequence.
