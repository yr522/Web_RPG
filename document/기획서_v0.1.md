## 3. 원소 (5종) · 상성 · 반응

### 원소
| 원소 | 효과 방향 (초안) | 색상 |
|---|---|---|
| 🔥 불 | 화상, 공격형 | 빨강 |
| 💧 물 | 감속, 제어형 | 파랑 |
| 🌿 땅 | 자연 컨셉(땅+풀). 덩굴, 보호막, 재생 | 초록 |
| ✨ 빛 | 회복·정화, 지원형 | 노랑 |
| 🌑 어둠 | 흡혈·저주 | 보라 |

### 상성 ✅
```
불 → 땅 → 물 → 불      빛 ⇄ 어둠
```
| 대상 | 유리 | 불리 | 같은 원소 |
|---|---|---|---|
| 일반 몬스터 | ×1.1 | ×0.9 | ×1.0 |
| 원소 몬스터 (기믹) | ×2.0 | ×0.5 | ×0.25 |

### 원소 반응 ✅
- 몬스터는 마지막으로 맞은 원소 1개를 기록 → 반응표 조합이면 추가 피해
- 기록은 **항상 덮어쓰기**, 순서 무관, 피해 = 공격 피해(상성 전)의 **50%**, 반응 피해에도 **상성 적용**
- 지금은 추가 피해만. 원소 없는 스킬은 기록을 바꾸지 않음

| 조합 | 반응 | | 조합 | 반응 |
|---|---|---|---|---|
| 불+땅 | 발화 | | 불+어둠 | 흑염 |
| 불+물 | 증발 | | 물+어둠 | 심연 |
| 땅+물 | 생명 | | 땅+빛 | 개화 |
| 불+빛 | 작열 | | | |

반응 없음: 물+빛, 땅+어둠, 빛+어둠

### 💬 원소 반응 논의 (2026-11-11, 미확정)
**발견한 문제: 원소마다 반응 개수가 다름**
| 원소 | 반응 개수 | 반응 상대 | 고를 수 있는 스킬 (모든 원소 스킬 제외) |
|---|---|---|---|
| 불 | 4 | 땅 물 빛 어둠 | 월참, 질풍참, 원소 기둥, 원소 파도 |
| 물 | 3 | 불 땅 어둠 | 월참, 원소 기둥, 사슬 화살 |
| 땅 | 3 | 불 물 빛 | 원소 기둥, 원소 파도, 사슬 화살, 소용돌이 |
| 빛 | 2 | 불 땅 | 월참, 질풍참, 소용돌이 |
| 어둠 | 2 | 불 물 | 사슬 화살, 소용돌이 (궁수만) |
- 빛⇄어둠은 상성 짝인데 반응이 없어 어색함
- 직업 안에서 반응 만들기: 마법사(불·물·땅) 셋 다 서로 반응 / 검사(불·물·빛) 물+빛 없음 / 궁수(땅·물·빛·어둠) 땅+어둠·빛+어둠·물+빛 없음
- 대신 빛·어둠은 같은 원소 말고는 불리한 상대가 없음
- 참고: 반응 피해의 원소는 게임 데이터에만 있음 (발화 불 / 증발 물 / 생명 땅 / 작열 빛 / 흑염 어둠 / 심연 어둠 / 개화 땅)

**나온 의견**
1. 반응 3개 추가 (물+빛, 땅+어둠, 빛+어둠) → 모든 원소가 4개씩 반응
   - 예시 이름·피해 원소: 무지개(물), 부패(어둠), 일식(빛)
   - 장점: 어떤 원소를 골라도 손해 없음, "다른 원소 번갈아 쓰기"로 단순
   - 단점: 어떤 조합이 반응하는지 고민하는 재미가 사라짐, 종류가 늘어 기억할 게 많아짐
   - 반대로 조합이 적으면 스킬 원소 고를 때 "정해진 길"이 생김
2. 모든 조합 반응 + 부가 효과는 마지막에 때린(터뜨린) 원소가 정함 → 외울 것은 원소 5개 성격뿐
3. 반응 피해는 그대로, 부가 효과는 직업별 "터뜨리는 스킬"로만 발동 (예: 질풍참(불) → 천붕(빛) = 작열 효과)
   - 후보: 검사 천붕 / 마법사 원소 기둥·원소 파도 / 궁수 소용돌이 화살
   - 문제: 스킬 원소는 배울 때 고정이라 선택이 배울 때로만 옮겨감. 검사는 천붕 직전이 거의 항상 질풍참이라 효과가 사실상 하나로 고정, 같은 원소로 배우면 반응이 영영 안 나옴
   - 문제: 쿨이 길어 효과가 가끔만 나오고, 슬라임뿐이라 체감할 무대가 없음. 같은 반응인데 효과가 있다 없다 해서 헷갈림
   - 장점: 나중에 같이 사냥할 때 직업 간 협동 (궁수가 묻히고 검사가 터뜨리기)

**유저 의견 (현재 방향)**
- 반응이 팡팡 터지는 게 도파민이 높고, ×0.5 상대에게 반응을 쓰면 잘 죽어서 지금도 전략성이 있음. "번갈아 다른 원소로 때리면 좋다"는 플레이로 알아챌 수 있음
- 나중에 스킬 수와 원소 선택지가 늘면 원하는 원소끼리 충분히 조합 가능
- 나중에는 원소마다 효과가 다른 디버프 스킬을 만들 수 있음 (예: 같은 스킬을 불로 고르면 받는 피해 증가, 물로 고르면 다른 효과)

**정리**
- 반응은 지금처럼 **피해 전용**으로 단순하게
- 원소별 차이는 나중에 스킬마다 원소별 효과를 붙여서 → 원소 성격을 모든 스킬에서 일관되게 (불 공격, 물 제어 …) 해야 외울 게 5개로 끝남. "버프 제거"는 초안 기준 빛(정화)에 가까움
- 원소 쌍 부족은 반응 추가보다 **스킬별 고를 수 있는 원소 목록**으로 푸는 쪽 (스킬 늘릴 때 직업별 원소 쌍 점검)
- 부가 효과는 **정예몹·보스가 생긴 뒤** 다시 결정 (후보: 의견 2, 의견 3)

### 💬 원소 컨셉 논의 (2026-11-11, 미확정)
**문제**: 사람들은 "파이어 메이지", "어둠 검사"처럼 원소 컨셉을 잡고 싶어 하는데, 지금 구조는 원소를 다양하게 섞을수록 유리함

**유저 의견**
- 한 원소만 쓰자는 게 아니라, **주력기·필살기는 한 원소로 고정 + 나머지 스킬은 다른 원소** = 적어도 2원소 조합
- 나중에 특성으로 "특정 원소 피해 증가"를 고를 수 있게 하면 주력기·필살기를 그 원소로 맞출 수 있음
- 차라리 **전직 루트가 갈라져서 2원소 조합**을 하게 하는 게 더 유의미할 수도
- 지금의 "여러 원소로 반응을 많이 터뜨리는" 원소술사 컨셉은 일부 직업·루트의 기믹으로 재사용 가능

**Claude 의견**
- 주력 원소 + 보조 원소(2원소)라면 지금 반응 구조와 잘 맞고, "주력 원소 피해 증가" 특성도 괜찮은 해결책 (정체성 = 불, 반응 = 불+물 증발)
- 특성으로 숫자만 올리는 방식의 주의점: 반응 추가 피해를 따라잡으려면 수치가 커야 하고, 그러면 섞는 사람도 찍어서 다시 정답이 하나로 쏠림 / 한 원소에 치우치면 같은 원소 몬스터(×0.25)에게 막힘
- **지금은 컨셉 자체가 안 되는 조합이 많음** → 스킬별 고를 수 있는 원소 목록을 먼저 손봐야 함
  - 어둠 검사: 어둠은 일섬·천붕뿐 / 빛·어둠 마법사: 마력탄뿐 / 불 궁수: 마법 화살·화살비뿐
- 한 원소 쪽에도 보상을 주는 안: 같은 원소로 계속 때리면 표식이 쌓여 **원소 폭발** (불 화상, 물 감속, 땅 묶기, 빛 회복, 어둠 흡혈) → "섞기 = 반응", "통일 = 폭발" 두 갈래. 특성은 각 갈래를 키우는 용도
- **전직 = 2원소 루트**는 1순위 후보로 좋음
  - 장점: 정체성이 반응 하나로 생김("증발 마법사", "흑염 검사"), 반응 부가 효과도 내 루트 것 하나만 알면 돼서 외울 게 적음, 대영웅 5인 = 5원소 세계관과 연결 가능
  - 주의: 루트마다 스킬·그림·밸런스가 따로 필요 → 직업당 2~3개로 시작 / 루트 원소와 같은 원소 몬스터를 넘는 수단 필요 / 전직 전에는 지금처럼 자유롭게 섞는 구간으로 두고 그 경험으로 루트를 고르게
- 순서 제안: 스킬 원소 목록 정리 → 한 원소 쪽 보상 또는 전직 루트 → 특성. 모두 정예몹·보스가 생긴 뒤 결정

## 4. 스킬 시스템 ✅

> 직업별 스킬 트리 한눈에 보기: `스킬트리_v0.1.md`

1. 직업당 **8칸** = 기본 스킬 4개 (Z/A/S/D, **교수님한테 순서대로**) + 힌트 스킬 2개 + 패시브 2개 (자세한 건 `스킬트리_v0.1.md`). 힌트 스킬·패시브도 교수님한테 배우고, 레벨만 되면 아무 때나. 힌트 스킬은 배우면 빈 키(Q W E)에 들어감
2. **일정 레벨마다 열림**: Lv1 기본1 / Lv3 기본2·패시브1 / Lv6 기본3·2라인 힌트 / Lv10 기본4·3라인 힌트·패시브2
3. 배울 때 **원소를 고름**. 이후에는 **스킬트리 초기화 주문서**로만 변경 (전체 초기화). 수업으로 올린 레벨(Lv1 넘는 만큼)은 **스킬 포인트(SP)**로 돌려받아 스킬 창에서 다시 찍음
4. **스킬 레벨**: 배우면 Lv1, **마스터 Lv5**. 레벨당 데미지 +10%
5. 스킬 레벨은 **아침 수업에 출석**해야만 오른다 (아침마다 1번, 스킬 1개 +1) → 마스터까지 꽤 걸림
6. 1번 스킬을 배우기 전에는 무속성 **기본 공격**
7. 원소 숙련도 없음
8. 스킬 이름은 현재 이름으로 확정
9. **스킬 창** (왼쪽 위 [스킬], K, 인벤토리 창과 같은 틀, 끌어서 옮기기)
   - 스킬 트리: 줄마다 왼쪽에 열리는 레벨(Lv.1·3·6·10, 열렸으면 노랑), 직업 스킬이 위에서부터 한 줄씩, 아래에 "레벨/5". 위아래 스킬을 둘 다 배웠으면 잇는 선이 노랑
   - 한 줄에 스킬 3칸(기본 · 2라인 힌트 · 3라인 힌트) + 맨 오른쪽 패시브 1칸. 안 쓰는 칸은 빈 칸 틀. 패시브도 Lv5까지 (SP + 버튼 포함)
   - 테두리 색 = 배운 원소. 안 배운 스킬·무속성은 흰색
   - SP: 평소엔 안 보임. 초기화 주문서로 돌려받은 SP가 있을 때만 왼쪽 위에 노란 굵은 글씨로 깜빡임. 배운 스킬 칸 오른쪽 위 + 버튼으로 1씩 찍음 (마스터 Lv5까지)
   - 오른쪽 아래 ▼: 스킬 키 칸(Z A S D Q W E)이 펼쳐짐. 배운 스킬을 끌어다 키에 등록(그 키에 있던 스킬은 빠지고, 다른 키에 있던 같은 스킬은 옮겨짐), 키끼리 끌면 옮기기·자리 바꾸기, 키 칸 우클릭(모바일은 두 번 터치)하면 그 키에서 빠짐
   - 화면 아래 고정 스킬 칸은 끌기 안 됨. 처음 키는 Z A S D = 직업 스킬 순서. 첫 직업 스킬이 등록된 키는 그 스킬을 배우기 전엔 기본 공격. 누르고 있으면 연타되는 기본기(기본 공격·일섬·마력탄)는 어느 키에 있어도 연타

### ⚔️ 검사 — 초식 연계
| 초식 | 동작 | 원소 | 쿨 |
|---|---|---|---|
| 일섬 | 포물선 베기 2회, 평타 역할 | 불 물 땅 빛 어둠 | 없음 |
| 월참 | 반달 베기 / ↑+월참: 올려베기 + 띄움 | 불 물 빛 | 짧음 |
| 질풍참 | 바라보는 방향으로 돌진 (각도 조절 없음) | 불 빛 | 김 |
| 천붕 | 광역 연속 베기, 질풍참 직후에만 | 불 물 땅 빛 어둠 | 없음 |
- 연계 보너스: 앞 초식 적중 후 0.9초 안에 다음 순서 초식 → +20% (검사 전용)

## 6. 레벨 & 퀘스트 ✅
- 필요 EXP = 40 + (Lv−1)×25. 일반 슬라임 10, 원소 슬라임 20

  - 제목 앞에 [반복] (예: [반복] 슬라임 퇴치). 퀘스트 창 완료 탭에는 처음 끝냈을 때 한 번만 올라가고, 다시 끝내도 그 자리 그대로

  1. **수락 선제 조건 충족** (레벨, 앞 퀘스트 완료 등)
  2. **퀘스트 수락** (NPC에게 말 걸어 받기)
  3. **완료 조건 충족** (목표 달성)
  4. **퀘스트 완료** (NPC에게 가서 보고)
  - 예외가 아니면 **각 단계는 플레이어가 직접 행동해야** 넘어감 (자동으로 다음 단계로 넘어가지 않음)
  - 지금 있는 예외: 자동 보고 퀘스트(mg5 "마법사와 숲으로": 도착하면 바로 완료), 혼자 하는 직업(마법사 직업의 마법공학의 유산: 동급생이 없어서 완료·다음 수락이 자동), 같은 NPC가 그 자리에서 이어서 주는 퀘스트는 한 대화에서 완료 + 다음 수락
- **이야기 퀘스트** (대화 NPC가 대사로 줌, 한 번만): 목표 종류
  - 처치(일반·원소·아무거나 N마리) / 모아 오기(물건 N개, 보고할 때 가져감) / 말 걸기(그 NPC에게) / 가 보기(그 맵에 들어가면 완료)
  - 레벨 달성(Lv N) / 스킬 배우기(아무 스킬 또는 지정 스킬) / 장비 끼기(아무 장비 또는 지정 장비)
  - **자동 보고**: 다 하면 NPC에게 안 가도 바로 끝남 / **다음 퀘스트**: 끝나면 바로 다음 퀘스트를 받음 (자동 수락)
  - **이야기 NPC 흐름** (기본): 받은 NPC에게 가서 보고해야 끝남 → NPC가 다음 맵으로 옮겨 가 있음 → 거기서 말 걸어 다음 퀘스트를 받음. 하는 퀘스트가 없으면 길 안내 화살표가 다음 퀘스트를 줄 NPC를 가리킴
  - **혼자 하는 직업** (solo): 그 직업이면 NPC가 없으므로 자동 보고 + 다음 퀘스트 자동 수락
  - **밤 고정**: 하는 동안 시간이 그날 밤 한가운데에 멈춤 / **동행**: 하는 동안 NPC가 따라다님 (연출, 무적, 맵을 넘어가면 같이 오고 멀어지면 뛰어옴, 움직일 때 걷기 모션)
  - **전달**: 받을 때 물건을 줌 → 그 물건 모아 오기 + 받을 사람에게 말 걸기. 받자마자 보고 가능 상태라 "완료" 큰 글씨는 안 뜨고 길 안내만

  - **목표 여러 개**: 한 퀘스트에 목표를 여러 개 넣을 수 있음 (예: 슬라임 5마리 + 점액 3개). 동시에 진행하고, 전부 해야 보고 가능. 말 걸기 목표가 있으면 그 NPC에게 보고

  - **끌어다 놓기**로 칸 옮기기. 빈 칸에 놓으면 옮기고, 물건이 있는 칸에 놓으면 자리 바꿈. 집은 칸은 파란 테두리, 놓을 칸은 파란 점선
    - 전체 탭: 칸 위치 그대로 보임. 다른 탭(장비·소비·기타): 그 종류만 앞에서부터 모아 보여 주고, 물건끼리만 자리 바꿈 가능
  - 아래쪽 **자동 정렬 버튼**(네모 안 가로줄 셋): 장비 → 소비 → 기타 순, 빈 칸은 뒤로
  - 가방이 가득 차면: 바닥 물건은 줍지 않고 남음, 매점에서 못 삼 ("가방이 가득 찼어")

- **장비는 껴도 가방에서 사라지지 않고 자리를 차지함** (가방이 꽉 차서 못 벗는 일 없음). 끼고 있는 장비 칸은 주황색 + 오른쪽 위 `on`
- 아이템 설명: PC는 마우스를 올리면, 모바일은 터치하면 그 자리에 반투명 검정 상자(이름 큰 글씨 + 설명). 모바일은 다른 곳을 터치하면 닫힘

### 정예몹 (2026-11-13, 수치 임시)

- 특성 1개: **신속**(이동 ×1.6) / **강철**(받는 피해 ×0.6, 안 밀림) / **분노**(HP 50% 아래로 내려가면 이동 ×1.5·몸통 피해 ×1.5, 붉게 빛남)
- 보스가 정예 특성을 받으면 특성만 (체력·크기는 그대로)

### 던전: 잊힌 공방 (2026-11-13, 임시)
- 입구: 공방 지하 바닥 왼쪽 포탈 (골렘을 처음 잡은 뒤의 지하). 들어가기 전에 물어봄
- 방 3개. 몬스터가 **웨이브**로 나오고, 한 웨이브를 다 잡으면 1.2초 뒤 다음 (WAVE 2 / 3 알림). 다 잡으면 오른쪽 **다음 방** 포탈이 나타남. 왼쪽 **나가기** 포탈은 언제나 (공방 지하로)
  - 1방 (공방 그림): 경비기계 A·D → B·D → C + 정예 신속 A
  - 2방 (공방 그림): C·D → B·C + 정예 분노 D → A 4마리 (정예 강철·신속 섞임)
  - 3방 (골렘 방 그림): D 3마리 → **고대 수호기계**(보스, HP 5000, 돌진형, 정예 강철·분노, 그림은 경비기계C 키운 임시) + A 2마리
- 3방을 다 잡으면 **던전 클리어** 보상 400 G + 600 EXP (매번)
- 던전에서 쓰러지면 공방 지하 위쪽에서 깨어남. 방에 다시 들어오면 처음 웨이브부터

### 마법 골렘 (보스)
- 크기 138×210 (플레이어 약 4.5배), 맞아도 안 밀리고 경직 없음. 항상 플레이어 쪽으로 천천히(42) 걸어옴
- **이동기 무적**: 검사 질풍참(돌진), 궁수 사슬 화살 끌려가기는 움직이는 동안 무적 (끝나는 순간까지)
- 2~3초마다 패턴
  1. **전방 내려치기**: 플레이어가 앞쪽 가까이(170) 있으면. 0.8초 떨면서 **반투명 상자로 범위 예고** → 앞쪽 폭 320·높이 32(바닥에 붙은 낮은 띠, 플레이어 키의 절반 + 조금)에 피해 45. **점프로 피함**. 몸통에 부딪혀 생긴 무적 중이어도 맞음 (이동기 무적만 피함)
  2. **돌진**: 멀면 45% 확률, 가까이 붙어 있어도 내려치기를 2번 연달아 쓰면 다음은 돌진 (플레이어 쪽으로). 예고할 때 방향을 고정하고 0.9초 뒤 그 방향으로 **벽에 닿을 때까지** 속도 210 (도중에 플레이어가 뒤로 가도 방향 안 바뀜). 벽에 닿으면 평소대로. 맞으면 피해 30 + **3초 기절**(조작 불가). 몸통 접촉 무적으로는 못 막음. 이동기로 뚫고 지나가면 안 맞음 (마법사 보완은 나중에)
  3. **천장 보안장치 (푸른 오브)**: 4.5초마다 조준선이 뜸 → **1.6초 동안 플레이어를 따라감**(흐린 선) → 방향 고정(굵게 깜빡임) 0.6초 뒤 발사 (속도 520, 플레이어 피해 25). 골렘이 **3번 맞으면 6초 기절 + 받는 피해 2배**. 깨어나면 다시 0부터. 기절하면 예고 중이던 골렘 패턴은 취소
- 난이도 배수는 보스 방에서 고른 난이도에만 적용 (사냥터·던전은 몬스터 표 그대로)
- 천장 오브 높이 150 (화면 위 보스 HP 바에 안 가리게 내림)
- **노멀부터 추가 패턴** (하드는 아직 구상 전이라 노멀과 같은 패턴)
  4. **대지 붕괴 (치명적)**: 골렘 HP가 75% · 50% · 25% 아래로 처음 내려갈 때마다. 1.6초 동안 바닥 전체 붉은 상자로 예고 → 그 순간 **땅에 서 있으면 최대 HP의 60% 피해**. 점프로 피함. 예고 중에 오브로 골렘을 기절시키면 그 대지 붕괴는 취소
  5. **천장 잔해 (환경)**: 5~7초마다 3개 (하나는 플레이어 머리 위, 나머지는 아무 데나). 1초 동안 세로 띠로 예고 → 떨어져서 폭 64에 피해 30
- **화면 위 보스 HP 바**: 보스가 있으면 메뉴 아래 가운데에 이름 + 긴 HP 바. 한 줄 = 약 1000 HP, 여러 겹 (빨강 ← 주황 ← 노랑 ← 초록 ← 파랑 ← 보라 순으로 깎임, 오른쪽에 남은 줄 수 x숫자). 깎인 자리는 흰 줄이 천천히 따라옴

## 11. 조작
- PC: ←→ 이동 / ↑ 포탈·대화·올려베기 / ↓+점프 발판 내려가기 / Space 점프 / Z A S D 스킬 / 1 2 포션 / C 캐릭터 창 / H 판정 보기 / Esc 닫기
- 모바일 가로: 왼쪽 방향패드 + 그 위 HP·MP 포션 버튼, 오른쪽 스킬 4 + 점프, NPC 터치
- 모바일 접속 조건: **가로 + 전체화면**. 세로면 "가로로 돌려줘!" → 가로인데 전체화면이 아니면 "전체화면으로 해줘!" + [전체화면] 버튼. 전체화면을 나가면 다시 뜸
  - 전체화면을 지원하지 않는 브라우저(아이폰 사파리)와 홈 화면에 추가해서 연 경우는 전체화면 안내 없음
- **왼쪽 위 메뉴 버튼**: 캐릭터(profile) · 인벤토리(inventory) · 퀘스트(spell) · 보스(battle) · 메뉴(pictoicon) · 귀환 · 전체 화면. 아이콘이 있는 버튼은 아이콘만 (이름은 마우스를 올리면), 귀환·전체 화면은 글자. 오른쪽 위 골드 앞에 gold 아이콘. skill 아이콘은 스킬 메뉴가 생기면 씀
- **세로 카메라** (위로 긴 맵: 마법 학교·공방 지하): 발이 화면 위에서 42% ~ 80% 사이에 있는 동안 카메라는 안 움직이고, 벗어날 때만 따라감 → 땅에서 점프해도 화면이 안 흔들림. 맨 아래 땅에 서면 원래 자리로 돌아옴
- **쓰러짐**: 체력이 0 이 되면 쓰러진 그림(걷기 시트 6번째 칸)으로 누워 있음 (조작 불가, 무적, 길 안내 화살표 숨김) → 깨어나는 곳으로
  - 화면 가운데 작은 창 (반투명 검정, 닫을 수 없음): "너의 죽음!" / [부활하기] / "자동 부활까지 N초" / 카운트다운 게이지
  - [부활하기]를 누르면 바로, 안 누르면 **20초** 뒤 저절로 부활

## 12. 기술 ✅ (2026-11-08 결정)
- 프로토타입: 순수 Canvas + JavaScript 단일 HTML, 저장은 localStorage
- **본 개발: 웹 유지, Phaser 3 + TypeScript + Vite** (고도 엔진은 검토 후 보류: 웹 빌드에서 쓰던 백엔드 연동·모바일 브라우저 성능·로딩이 불리)
- **멀티는 여유 있을 때 추가.** 지금은 연결 없이 **멀티 대비 구조만** 만들어 둔다

### 멀티 대비 구조
- 폴더: `shared/`(게임 로직 + 데이터, 브라우저·서버 공용) · `client/`(Phaser 화면·입력) · `server/`(나중에)
- **로직과 그리기 분리**: `shared`의 시뮬레이션은 Phaser·DOM을 모름. 화면은 상태를 읽어서 그리기만
- **입력 = 명령**: 키 입력을 `{플레이어, 스킬 슬롯, 방향, 조준}` 같은 명령으로 바꿔 시뮬레이션에 넣음 → 나중에 이 명령을 그대로 서버로 보냄
- **결과 = 이벤트**: 피해, 원소 반응, 골드 드랍·획득, 레벨업 등은 이벤트로 내보내고 화면은 이벤트로 이펙트를 재생
- **세션 교체 구조**: 지금은 `LocalSession`(브라우저에서 시뮬레이션 실행), 나중에 `RemoteSession`(서버 연결)으로 교체
- **고정 틱**으로 시뮬레이션, 시간·난수는 밖에서 주입 (낮밤 시계도 교체 가능하게)
- 모든 엔티티에 ID, 플레이어도 처음부터 여러 명 가능한 구조 (싱글은 1명짜리 방)
- **저장소 교체 구조**: 지금은 `LocalStore`(localStorage), 나중에 `SupabaseStore`
- 스킬·몬스터·맵·퀘스트·상점은 데이터 파일로 분리

### 에셋 불러오기 규칙 (2026-11-13 정함, 아직 안 만듦 · 지금은 전부 처음에 받음)
던전·몬스터가 늘어도 처음 켜는 시간이 늘지 않게, 받는 때를 둘로 나눈다.

**① 처음 접속할 때 받음** (작고, 어디서든 바로 필요한 것)
| 종류 | 예 |
|---|---|
| UI 그림 | 메뉴 아이콘, 장비 칸 아이콘, 아이템 아이콘, 동전, 폰트 |
| 플레이어 기본 몸·모션 | 걷기 시트(서기·걷기·점프·앉기·쓰러짐), 직업별 공격 모션 |
| 내 캐릭터가 지금 낀 장비·외형 파츠 | 모자·옷·무기·머리 등 (나중에 외형이 많아지면 안 낀 것은 ② 로) |
| 공통 이펙트 | 타격, 원소 반응, 레벨업, 포탈 |
| 내 직업 스킬 이펙트 | 다른 직업 스킬 이펙트는 멀티에서 다른 사람이 보일 때 ② 로 |
| NPC 초상화 | 대화창 그림 (개수가 많아지면 ② 로) |

**② 맵에 들어갈 때 받고, 멀어지면 내림** (크고, 그 맵에서만 필요한 것)
| 종류 | 받는 때 | 내리는 때 |
|---|---|---|
| 배경 그림 | 지금 맵 + **포탈로 이어진 옆 맵을 미리** (뒤에서 몰래) | 포탈 2번 이상 떨어진 맵 |
| 그 맵 몬스터 그림 | 배경과 같이 (옆 맵 몬스터도 미리) | 배경과 같이 |
| 보스 그림·보스 이펙트 | 보스 방 입장 포탈이 있는 맵에서 미리 | 보스 방에서 멀어지면 |
| 컷신 전용 그림 | 그 컷신이 나올 퀘스트를 받았을 때 | 퀘스트가 끝나면 |
| 배경 음악 (나중에) | 맵에 들어갈 때 (흘려 받으며 재생) | 맵을 나가면 |

- "내림" = 메모리에서만 빼는 것. 파일은 브라우저가 기억하고 있어서 다시 오면 바로 뜬다 (다시 접속해도)
- 맵 넘어갈 때 화면이 까맣게 됐다 밝아지는 동안 그림을 올린다 → 혹시 늦어도 버벅임이 아니라 전환으로 보임
- 받는 중 끊김이 생길 수 있는 경우: 처음 접속해서 옆 맵을 다 받기 전에 바로 포탈을 탈 때 정도

**파일 형식**
- 배경 그림: **WebP** 로 줄여서 올림 (PNG 2MB → 200~300KB, 눈으로 차이 거의 없음). 유저는 PNG 로 줘도 되고 줄이는 건 Claude
- 캐릭터·몬스터·이펙트 같은 도트 그림: **PNG 그대로** (줄이면 도트가 뭉개짐). 몬스터·이펙트가 많아지면 Claude 가 여러 장을 한 장에 모아 붙여 씀

**메모리·성능 메모**
- 그림은 파일 크기와 상관없이 화면에 올리면 원래 크기로 풀린다 (배경 한 장 ≈ 9MB). 그래서 ② 의 "내림"이 중요
- 한계는 게임 전체 분량이 아니라 **한 화면에 동시에 뜨는 몬스터·이펙트 수**. PC 는 수십 개도 여유, 싼 폰이 기준 → 이펙트 개수 상한, 큰 이펙트는 그림 한 장으로
- 시뮬레이션은 지금 있는 맵 하나만 돌아가서 맵·던전 수가 늘어도 계산량은 그대로

### 멀티 붙일 때 계획 (나중에)
- 클라이언트: 정적 사이트 배포
- Supabase: 로그인, 캐릭터 저장, 채팅
- Render(Node, Colyseus 등): 맵마다 방 하나, 몬스터·피해·원소 반응·골드 줍기는 서버가 판정
- Render 무료 플랜: 15분 무트래픽 시 잠듦(WebSocket 메시지도 트래픽으로 침), 월 750시간, 파일 휘발, 언제든 재시작 가능 → 저장은 Supabase, 자동 재접속 필수, 타이틀 화면에서 서버 미리 깨우기
- 순서: ① Phaser 이식(싱글) → ② Supabase 로그인·저장 → ③ 같은 맵 친구 보이기 + 채팅 → ④ 같이 사냥

## 📖 미니 챕터: 마법공학의 유산 (유저 시나리오, 2026-11-12)
- 수락 조건: Lv 3
- 개요: 학교 뒤 숲 깊은 곳에서 밤마다 이상한 소음이 들린다는 민원
- 줄거리(검사/궁수): 동급생 마법사(플레이어로 고를 수 있는 그 마법사, **여자**)가 불면을 호소 → 친구를 위해 수색 → 숲 깊은 곳의 잊혀진 마법공방 발견
- 줄거리(마법사): 며칠 밤 속삭임·소음에 잠을 못 자던 주인공이 혼자 수색 → 공방 발견

**퀘스트 순서 (검사/궁수)**
1. 학교 로비에서 피곤해하는 마법사에게 말 걸기 (사연 듣기)
2. 학교 뒤 숲 둘러보고 오기 (처음엔 공방 입구가 가려져 못 찾음)
3. 마법사에게 "아무것도 없다" 알리기
4. 밤에 내 기숙사 방 맵에서 잠자기 (이벤트성) → 밤중에 마법사가 찾아와 소리가 들린다고 깨움
5. (자동 수락) 마법사와 숲으로 (밤 고정) → 숲 깊은 곳 맵에서 형체 없는 목소리("접근하지 마라") → 없던 몬스터 등장
   - 몬스터 없는 맵 / 있는 맵을 따로 두고, 연출 후 같은 자리의 몬스터 있는 맵으로 옮김. 포탈 연결도 영구히 몬스터 있는 맵으로
6. 길을 막는 기계 몬스터 처치 (경비기계A 지역)
7. 다음 맵에서 다른 기계 몬스터 처치 (경비기계B 지역)
8. 숨겨진 입구 맵 발견 → 들어가려면 장치가 필요, 그걸 가진 경비기계B를 찾자 (낮은 확률 퀘스트 템, 최대 1개)
9. 공방 입장 → 컷신 (마법사와 둘러보기), 공방 지하에서 강한 마력이 느껴짐
10. 공방 지하: 경비기계C(뚜벅이) + 경비기계D(소형, 날아다님, 부딪히기만) / 맵 안 몬스터 전부 처치
    - 들어오면 **맵에 갇힘** (시스템상 나갈 수 없음). 다 잡으면 정해진 다음 포탈(하단 중앙)로만 갈 수 있음, 되돌아갈 수 없음
    - 포탈 들어가기 전 확인: "강력한 기운이 느껴집니다. 이동하시겠습니까?"
    - 골렘까지 잡으면 지하는 몬스터가 다시 생기는 보통 사냥터로 영구 변경
11. 컷신 → 보스 [마법 골렘 - 마법공학의 유산] (기본 솔플) → 작동 정지, 순수한 마력 결정체(골렘의 원동력, 드랍템 아님)를 떨굼 → 서브빌런이 나타나 훔쳐 감
12. 마법사와 대화 (후일담)
13. 선생님께 알리고 세계관 역사에 대한 짧은 대화 → 끝
- 연계 퀘스트 **[장비에 깃든 마법]** 수락 가능 → 장비 부가옵션 부여·리롤·강화 오픈
