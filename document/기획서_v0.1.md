### 핵심 컨셉
- **직업은 원래 가진 전투 방식**이고, **마법학교에서는 원소의 힘을 배운다.**
- 같은 직업이라도 스킬마다 고른 원소에 따라 완전히 다른 캐릭터로 성장한다.
- 정해진 원소 조합을 이어 맞히면 **원소 반응**이 터진다.
- 세계는 **실시간으로 아침/낮/밤**이 흐르고, **아침 수업에 출석**해야 스킬이 성장한다.

## 3. 원소 (5종) · 상성 · 반응

### 원소
| 원소 | 효과 방향 (초안) | 색상 |
|---|---|---|
| 🔥 불 | 화상, 공격형 | 빨강 |
| 💧 물 | 감속, 제어형 | 파랑 |
| 🌿 땅 | 자연 컨셉(땅+풀). 덩굴, 보호막, 재생 | 초록 |
| ✨ 빛 | 회복·정화, 지원형 | 노랑 |
| 🌑 어둠 | 흡혈·저주 | 보라 |

### 상성 ✅
```
불 → 땅 → 물 → 불      빛 ⇄ 어둠
```
| 대상 | 유리 | 불리 | 같은 원소 |
|---|---|---|---|
| 일반 몬스터 | ×1.1 | ×0.9 | ×1.0 |
| 원소 몬스터 (기믹) | ×2.0 | ×0.5 | ×0.25 |

### 원소 반응 ✅
- 몬스터는 마지막으로 맞은 원소 1개를 기록 → 반응표 조합이면 추가 피해
- 기록은 **항상 덮어쓰기**, 순서 무관, 피해 = 공격 피해(상성 전)의 **50%**, 반응 피해에도 **상성 적용**
- 지금은 추가 피해만. 원소 없는 스킬은 기록을 바꾸지 않음

| 조합 | 반응 | | 조합 | 반응 |
|---|---|---|---|---|
| 불+땅 | 발화 | | 불+어둠 | 흑염 |
| 불+물 | 증발 | | 물+어둠 | 심연 |
| 땅+물 | 생명 | | 땅+빛 | 개화 |
| 불+빛 | 작열 | | | |

반응 없음: 물+빛, 땅+어둠, 빛+어둠

### 💬 원소 반응 논의 (2026-11-11, 미확정)
**발견한 문제: 원소마다 반응 개수가 다름**
| 원소 | 반응 개수 | 반응 상대 | 고를 수 있는 스킬 (모든 원소 스킬 제외) |
|---|---|---|---|
| 불 | 4 | 땅 물 빛 어둠 | 월참, 질풍참, 원소 기둥, 원소 파도 |
| 물 | 3 | 불 땅 어둠 | 월참, 원소 기둥, 사슬 화살 |
| 땅 | 3 | 불 물 빛 | 원소 기둥, 원소 파도, 사슬 화살, 소용돌이 |
| 빛 | 2 | 불 땅 | 월참, 질풍참, 소용돌이 |
| 어둠 | 2 | 불 물 | 사슬 화살, 소용돌이 (궁수만) |
- 빛⇄어둠은 상성 짝인데 반응이 없어 어색함
- 직업 안에서 반응 만들기: 마법사(불·물·땅) 셋 다 서로 반응 / 검사(불·물·빛) 물+빛 없음 / 궁수(땅·물·빛·어둠) 땅+어둠·빛+어둠·물+빛 없음
- 대신 빛·어둠은 같은 원소 말고는 불리한 상대가 없음
- 참고: 반응 피해의 원소는 게임 데이터에만 있음 (발화 불 / 증발 물 / 생명 땅 / 작열 빛 / 흑염 어둠 / 심연 어둠 / 개화 땅)

**나온 의견**
1. 반응 3개 추가 (물+빛, 땅+어둠, 빛+어둠) → 모든 원소가 4개씩 반응
   - 예시 이름·피해 원소: 무지개(물), 부패(어둠), 일식(빛)
   - 장점: 어떤 원소를 골라도 손해 없음, "다른 원소 번갈아 쓰기"로 단순
   - 단점: 어떤 조합이 반응하는지 고민하는 재미가 사라짐, 종류가 늘어 기억할 게 많아짐
   - 반대로 조합이 적으면 스킬 원소 고를 때 "정해진 길"이 생김
2. 모든 조합 반응 + 부가 효과는 마지막에 때린(터뜨린) 원소가 정함 → 외울 것은 원소 5개 성격뿐
3. 반응 피해는 그대로, 부가 효과는 직업별 "터뜨리는 스킬"로만 발동 (예: 질풍참(불) → 천붕(빛) = 작열 효과)
   - 후보: 검사 천붕 / 마법사 원소 기둥·원소 파도 / 궁수 소용돌이 화살
   - 문제: 스킬 원소는 배울 때 고정이라 선택이 배울 때로만 옮겨감. 검사는 천붕 직전이 거의 항상 질풍참이라 효과가 사실상 하나로 고정, 같은 원소로 배우면 반응이 영영 안 나옴
   - 문제: 쿨이 길어 효과가 가끔만 나오고, 슬라임뿐이라 체감할 무대가 없음. 같은 반응인데 효과가 있다 없다 해서 헷갈림
   - 장점: 나중에 같이 사냥할 때 직업 간 협동 (궁수가 묻히고 검사가 터뜨리기)

**유저 의견 (현재 방향)**
- 반응이 팡팡 터지는 게 도파민이 높고, ×0.5 상대에게 반응을 쓰면 잘 죽어서 지금도 전략성이 있음. "번갈아 다른 원소로 때리면 좋다"는 플레이로 알아챌 수 있음
- 나중에 스킬 수와 원소 선택지가 늘면 원하는 원소끼리 충분히 조합 가능
- 나중에는 원소마다 효과가 다른 디버프 스킬을 만들 수 있음 (예: 같은 스킬을 불로 고르면 받는 피해 증가, 물로 고르면 다른 효과)

**정리**
- 반응은 지금처럼 **피해 전용**으로 단순하게
- 원소별 차이는 나중에 스킬마다 원소별 효과를 붙여서 → 원소 성격을 모든 스킬에서 일관되게 (불 공격, 물 제어 …) 해야 외울 게 5개로 끝남. "버프 제거"는 초안 기준 빛(정화)에 가까움
- 원소 쌍 부족은 반응 추가보다 **스킬별 고를 수 있는 원소 목록**으로 푸는 쪽 (스킬 늘릴 때 직업별 원소 쌍 점검)
- 부가 효과는 **정예몹·보스가 생긴 뒤** 다시 결정 (후보: 의견 2, 의견 3)

## 4. 스킬 시스템 ✅

1. 직업당 스킬 4개 (Z/A/S/D). **교수님한테 순서대로** 배운다.
2. **일정 레벨마다 다음 스킬이 열림**: 1번 Lv1 / 2번 Lv3 / 3번 Lv6 / 4번 Lv10 (프로토타입 수치)
3. 배울 때 **원소를 고름**. 이후에는 **스킬트리 초기화 주문서**로만 변경 (전체 초기화, 스킬 레벨은 유지)
4. **스킬 레벨**: 배우면 Lv1, **마스터 Lv5**. 레벨당 데미지 +10%
5. 스킬 레벨은 **아침 수업에 출석**해야만 오른다 (아침마다 1번, 스킬 1개 +1) → 마스터까지 꽤 걸림
6. 1번 스킬을 배우기 전에는 무속성 **기본 공격**
7. 원소 숙련도 없음
8. 스킬 이름은 현재 이름으로 확정

### ⚔️ 검사 — 초식 연계
| 초식 | 동작 | 원소 | 쿨 |
|---|---|---|---|
| 일섬 | 포물선 베기 2회, 평타 역할 | 불 물 땅 빛 어둠 | 없음 |
| 월참 | 반달 베기 / ↑+월참: 올려베기 + 띄움 | 불 물 빛 | 짧음 |

- 연계 보너스: 앞 초식 적중 후 0.9초 안에 다음 순서 초식 → +20% (검사 전용)

### 🔮 마법사 — 캐스팅
- 캐스팅 중 이동 불가, 맞아도 안 끊김(슈퍼아머). 예외: 보스 **전설행동**

| 마력탄 | 중거리 마력탄. 기본 스킬, 쿨 없음, 눈에 띄는 텀 | 불 물 땅 빛 어둠 |
| 원소 기둥 | 앞쪽 가장 가까운 몬스터 발밑에 기둥. 인식 범위 밖이면 사용 불가 | 불 물 땅 |
| 원소 파도 | 앞으로 차례차례 생성되는 불길/가시, 칸마다 타격, 겹치지 않음 | 불 땅 |
| 마력 해방 | 10초간 캐스팅 −50%, 쿨 2배속. 쿨 60초는 버프 끝난 뒤부터 | 없음 |

- 누르면 바로 나가는 스킬(검사 월참, 궁수 소용돌이·화살비)은 맞아도 안 끊김 (슈퍼아머, 피해는 받음)

## 5. 능력치 ✅ (임시 컨셉, 나중에 제대로 다듬기)
- 레벨업마다 **스탯 포인트 3** → **직접 분배**
- 캐릭터 생성 때 **포인트 5**를 근력·민첩·지능에 직접 분배 (시작값 각 5, 안 쓴 포인트는 남은 포인트로 넘어감) — 임시

| 스탯 | 효과 |
|---|---|
| 근력 | 근거리(검사) 데미지 + 최대 체력 |
| 민첩 | 궁수 데미지 + 이동속도 |
| 지능 | 마법사 데미지 + MP 자연회복 속도 |

프로토타입 공식: 공격력 = 20 + (주 스탯 − 5) × 1.6 / 최대 HP = 직업 기본 + (Lv−1)×8 + (근력−5)×6 / 이동속도 = 260 + (민첩−5)×6 (최대 420) / MP 회복 = 직업 기본 × (1 + (지능−5)×0.08)

## 6. 레벨 & 퀘스트 ✅
- 필요 EXP = 40 + (Lv−1)×25. 일반 슬라임 10, 원소 슬라임 20
- 레벨업 시 HP·MP 회복, 새 스킬이 열리면 알림
- **반복 퀘스트** (교수님): 받기 → 조건 달성 → 교수님께 보고 → 보상 → 다시 받기
  - 슬라임 퇴치: 학교 뒷숲에서 일반 슬라임 8마리 (EXP 60 + Lv×12)
  - 원소 슬라임 조사: 원소 슬라임 서식지에서 원소 슬라임 5마리 (EXP 100 + Lv×18)
- 진급 시험, 장비, 보스는 **나중에**

## 7. 골드 & 상점 ✅
- 몬스터를 잡으면 골드가 튀어나와 바닥에 떨어짐
  - 일반 슬라임 5~9G, 원소 슬라임 12~18G (원소 슬라임은 동전 2개로 나눠 떨어짐)
- **캐릭터 몸이 닿아야 획득** (자동 줍기 없음)
- **30초 지나면 자동 소멸**. 마지막 5초는 깜빡임
- 맵을 옮기면 바닥의 골드는 사라짐
- 학교 맵의 **매점 모리** NPC (↑ / 터치·클릭)

| 상품 | 가격 | 효과 |
|---|---|---|
| 🧪 HP 포션 | 30G | HP 50 회복 · `1` 키 |
| 💧 MP 포션 | 30G | MP 40 회복 · `2` 키 |
| 📜 스킬트리 초기화 주문서 | 1000G | 배운 스킬 전부 초기화 → 교수님께 원소 다시 골라 배움. 스킬 레벨 유지 |

- 포션은 1개/10개 단위 구매, 사용 간격 0.8초, 가득 차 있으면 못 씀
- 초기화 주문서는 캐릭터 창(C)의 소지품에서 두 번 눌러 사용
- 새 캐릭터는 HP·MP 포션 3개씩 들고 시작

## 8. 맵 ✅
```
[마법 학교] ⇄ [학교 뒷숲] ⇄ [원소 슬라임 서식지]
```
| 맵 | 폭 | 내용 |
|---|---|---|
| **마법 학교** | 1700 | 허브. 교수님 + 매점, 포탈. 몬스터 없음, 체력 천천히 회복. 쓰러지면 여기서 깨어남 |
| **학교 뒷숲** (사냥터 1) | 1700 | **일반 슬라임만** 7마리 |
| **원소 슬라임 서식지** (사냥터 2) | 1900 | **원소 슬라임만** 10마리 (5원소 각 2마리) |

- 포탈 앞에서 **↑**로 이동

## 12. 기술 ✅ (2026-11-08 결정)
- 프로토타입: 순수 Canvas + JavaScript 단일 HTML, 저장은 localStorage
- **본 개발: 웹 유지, Phaser 3 + TypeScript + Vite** (고도 엔진은 검토 후 보류: 웹 빌드에서 쓰던 백엔드 연동·모바일 브라우저 성능·로딩이 불리)
- **멀티는 여유 있을 때 추가.** 지금은 연결 없이 **멀티 대비 구조만** 만들어 둔다

### 멀티 대비 구조
- 폴더: `shared/`(게임 로직 + 데이터, 브라우저·서버 공용) · `client/`(Phaser 화면·입력) · `server/`(나중에)
- **로직과 그리기 분리**: `shared`의 시뮬레이션은 Phaser·DOM을 모름. 화면은 상태를 읽어서 그리기만
- **입력 = 명령**: 키 입력을 `{플레이어, 스킬 슬롯, 방향, 조준}` 같은 명령으로 바꿔 시뮬레이션에 넣음 → 나중에 이 명령을 그대로 서버로 보냄
- **결과 = 이벤트**: 피해, 원소 반응, 골드 드랍·획득, 레벨업 등은 이벤트로 내보내고 화면은 이벤트로 이펙트를 재생
- **세션 교체 구조**: 지금은 `LocalSession`(브라우저에서 시뮬레이션 실행), 나중에 `RemoteSession`(서버 연결)으로 교체
- **고정 틱**으로 시뮬레이션, 시간·난수는 밖에서 주입 (낮밤 시계도 교체 가능하게)
- 모든 엔티티에 ID, 플레이어도 처음부터 여러 명 가능한 구조 (싱글은 1명짜리 방)
- **저장소 교체 구조**: 지금은 `LocalStore`(localStorage), 나중에 `SupabaseStore`
- 스킬·몬스터·맵·퀘스트·상점은 데이터 파일로 분리

### 멀티 붙일 때 계획 (나중에)
- 클라이언트: 정적 사이트 배포
- Supabase: 로그인, 캐릭터 저장, 채팅
- Render(Node, Colyseus 등): 맵마다 방 하나, 몬스터·피해·원소 반응·골드 줍기는 서버가 판정
- Render 무료 플랜: 15분 무트래픽 시 잠듦(WebSocket 메시지도 트래픽으로 침), 월 750시간, 파일 휘발, 언제든 재시작 가능 → 저장은 Supabase, 자동 재접속 필수, 타이틀 화면에서 서버 미리 깨우기
- 순서: ① Phaser 이식(싱글) → ② Supabase 로그인·저장 → ③ 같은 맵 친구 보이기 + 채팅 → ④ 같이 사냥
