# 스킬 트리 v0.1

직업별 스킬 트리 정리 (2026-11-13 기준, 지금 게임에 들어간 것).
규칙 원본은 기획서 4장, 수치는 기획서 14장 / `shared/data/classes.ts`.

---

## 공통 규칙

- 직업당 줄 4개. 줄마다 왼쪽에 **열리는 레벨** (Lv.1 / 3 / 6 / 10)
- 한 줄 = **스킬 3칸 + 패시브 1칸**
  - 첫 칸: 지금 있는 직업 스킬 (교수님한테 순서대로 배움)
  - 갈래 2칸: 빈 칸 (아직 구상 전, 다 찍을 수 있게 할 예정)
  - 패시브: 빈 칸 (아직 구상 전)
- 배울 때 **원소 고름** → 칸 테두리 색. 무속성·안 배운 칸은 흰색
- 스킬 레벨 Lv1 → **마스터 Lv5**, 레벨당 데미지 +10% (마스터 = +40%)
- 레벨은 **아침 수업 출석**으로만 오름 (아침마다 1번, 스킬 1개 +1)
- 원소 바꾸기: **스킬트리 초기화 주문서** (전체 초기화). 수업으로 올린 레벨은 SP로 돌려받아 스킬 창에서 다시 찍음
- 1번 스킬 배우기 전엔 무속성 **기본 공격** (계수 0.6)
- 스킬 키: Z A S D = 직업 스킬 순서, Q W E = 빈 키
