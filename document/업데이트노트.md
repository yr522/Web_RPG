## 2026-11-12

### 마법공학의 유산: 공방 ~ 보스전
- 공방 내부 맵 (배경 그림), 공방 지하 (세로로 긴 맵, 양옆 발판 3개씩, 갇힘 → 다 잡으면 골렘 방 포탈 + 이동 확인), 골렘 방
- 경비기계C(뚜벅이)·D(날아다님), 보스 마법 골렘: 내려치기 · 맵 끝까지 돌진(맞으면 3초 기절) · 천장 보안장치 탄에 3번 맞으면 기절 + 피해 2배
- 퀘스트 이어서: 공방 퀘스트 템으로 입장 → 지하 → 골렘 처치. 골렘을 잡으면 지하가 보통 사냥터로
- 줄거리용 임시 대사 (마법사 동급생·침대), 세로로 긴 맵 카메라

### 마법공학의 유산: 퀘스트 흐름 (대사 없이 진행만)
- 학교 마법사 동급생(Lv 3) → 숲 둘러보기 → 밤에 기숙사 침대에서 자기 → 마법사와 밤의 숲으로(동행, 밤 고정) → 경비기계A·B 처치 → 공방 입구 → 공방 퀘스트 템(경비기계B 5%, 최대 1개)까지
- 마법사 직업은 밤에 침대에서 자면 혼자 바로 시작
- 기숙사 방 맵 (학교 오른쪽 끝), 조용한 숲 → 몬스터 있는 숲으로 바뀌기, 퀘스트에 따라 NPC 자리·포탈이 바뀜
- 퀘스트 자동 보고·다음 퀘스트 자동 수락, 대사 조건에 시간대

### 맵 (마법공학의 유산 쪽)
- 학교 뒷숲 포탈을 학교 왼쪽 끝으로 옮기고 오른쪽은 막음. 기숙사 표지판은 오른쪽 끝으로
- 뒷숲·원소 슬라임 서식지를 좌우로 뒤집어서 왼쪽으로 들어가는 방향으로
- 새 맵: 갈림길 → (가운데 포탈) 경비기계A 지역 → 경비기계B 지역 → 공방 입구
- 공방 입구에 배경 그림(초안), 그림 속 풀밭 줄에 맞춰 땅 높이
- 기획서에 미니 챕터 "마법공학의 유산" 시나리오 정리

### 몬스터
- 경비기계A (걸어서 쫓아옴), 경비기계B (멈춰 떨다가 돌진). 그림·수치 임시
- 처치 퀘스트를 몬스터 종류로 셈 (기계를 잡아도 슬라임 퇴치 숫자는 안 오름)

### 퀘스트 종류 확장
- 새 목표: 레벨 달성 · 스킬 배우기 · 장비 끼기
- 전달 퀘스트: 받을 때 물건을 받아서 다른 NPC에게 가져다주기
- 대사 조건 추가: 레벨 · 가방에 물건 있음 · 직업 · 하나라도/아님
- 대사 효과 추가: 물건·골드 주고받기
- 대사 중 효과가 실패하면(가방 가득 등) 대화가 거기서 끝남
- 이야기 테스트 NPC 뒤에 편지 전달 → 목표 여러 개(장비 끼기 + Lv 3 + 슬라임 2마리) 테스트 추가

### 저장 구조 정리
- 퀘스트 하나에 목표 여러 개 (예: 슬라임 5마리 + 점액 3개, 전부 해야 보고). 왼쪽 퀘스트 칸에 `3/5 · 1/3`처럼 표시
- 말 걸기 목표가 있으면 완료 알림·길 안내가 그 NPC 쪽으로
- 예전 저장을 불러올 때 지금 형태로 자동 변환, 데이터에서 지운 퀘스트·물건은 정리 (시나리오로 테스트 퀘스트를 지워도 저장 안 깨짐)

### 장비창 아이콘
- 장비창 빈 칸에 부위 아이콘 8종 (모자·반지·목걸이·무기·상의·장갑·하의·신발)
- 장비 칸 배경은 비어 있든 끼고 있든 반투명

### 캐릭터 생성 화면
- 마법사 배너를 새 일러스트(남·여)로 교체

### 이야기 장치 (시나리오용)
- **퀘스트 종류**: 처치 · 이름표 몬스터 처치(보스용) · 모아 오기 · 말 걸기 · 가 보기
- **퀘스트 보상**: EXP · 골드 · 아이템
- **상황별 대사**: 이야기 진행·퀘스트 상태에 따라 NPC 대사가 바뀜. 대사 중간에 퀘스트 주기·보고, 컷신, 플레이어 대사
- **컷신**
  - 카메라 이동·줌인, 조작 막기, UI 숨기기
  - 캐릭터 걷기·모션(서기·앉기·점프·공격)·방향·말풍선
  - 연출용 몬스터 등장 → 그 자리에서 진짜 몬스터로 바꿔 싸움 시작
- **길 안내 화살표**: 하는 중인 퀘스트 목적지(다른 맵이면 그쪽 포탈) 방향으로 머리 위 화살표
- 학교 왼쪽 "이야기 테스트 NPC"로 전부 시험해 볼 수 있음 (시나리오가 들어오면 지움)

### 맵
- 슬라임 맵 줄이기: 학교 뒷숲 1700 → 1300 (슬라임 5마리), 원소 슬라임 서식지 1900 → 1400 (6마리)

### 인벤토리·장비 (I 키)
- 가방 60칸 (4×15, 오른쪽 휠), 탭 전체·장비·소비·기타
- 끌어다 놓기로 칸 옮기기·자리 바꾸기, 자동 정렬 버튼, 빈 칸은 그대로 둠
- 장비창 9칸 (모자 / 반지1·목걸이·무기 / 반지2·상의·장갑 / 하의·신발)
- 장비는 껴도 가방에 남음 (주황 + `on`), 우클릭(모바일 두 번 터치)으로 장착·해제·포션 사용
- 아이템 설명 플로팅 (마우스 올림 / 터치)
- 창 크기가 화면에 맞춰 바뀌고, 윗줄·아랫줄을 끌어 옮길 수 있음
- 매점 모리에서 테스트 장비 구매 (근력 +1, 반지는 모든 능력치 +1)

### 아이템
- 슬라임(일반·원소)이 40% 확률로 **슬라임 점액** 드롭, 몸이 닿아야 주움

### 대화·말풍선
- 대화 NPC 양식 + 테스트 NPC (대사 → 선택지 → 답변)
- 머리 위 말풍선 (NPC·플레이어), 다가가면 "윗키를 눌러 상호작용하세요"
- 대사창 높이 고정, 스크롤바 숨김

### 화면
- 창 크기·전체화면이 바뀌면 게임 화면 다시 맞춤
- 모바일: 가로로 돌린 다음 전체화면 버튼
