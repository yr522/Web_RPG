# 마법학교 웹게임 세계관 v0.1

> 작성: 2026-11-08 · 추가: 2026-11-12 (마신·성녀·대영웅의 진상) · 상태: 큰 틀 초안 (유저 작성 + Claude 정리)
> ✅ = 유저가 정한 것 · 💡 = Claude 제안 (미확정)

---

## 1. 구조 ✅
- 세계관: 마법과 몬스터가 있는 평범한 RPG 세계
- 플레이어가 고르는 **직업마다 개인 스토리**가 있고, 개인 스토리가 **메인 스토리의 큰 축**을 맡는다
- 직업별로 **디폴트 주인공 설정**이 있다
- **커스텀 가능한 것**: 이름, 외형
  - 외형은 **고정 외형으로 시작**하고, 나중에 커스터마이징 가능 (메이플스토리 방식)
- **고정인 것**: 스토리, 대사

## 2. 이야기 배경 ✅
- **마신**: 세계관 최강자, 악인
- 마신이 한 짓: **마력 그 자체인 신**을 죽였다. 세상은 완전히 멸망해 마신의 손에 들어갈 뻔했다
- 길고 긴 전쟁 끝에 마신은 죽었고, 세상에 평화가 찾아왔다
- **성녀 1인과 대영웅 5인**이 함께 희생해서 마신을 봉인했다 (← 세상에 알려진 역사. 진상은 아래 2-1)
- 봉인된 곳: 왕국에서 멀리 떨어진, **나라 하나만 한 크기의 지역**. 마기 때문에 아무도 살지 않는다
- 마신은 죽으면서 **민들레 씨앗을 뿌리듯 세상에 자기 힘을 뿌렸다**. 씨앗 중 하나라도 신성이 싹트기를 고대한다

## 2-1. 과거의 진상 ✅ (2026-11-12 추가 · 아무도 모르는 이야기)

### 😈 마신
- **과거 성녀의 언니** (자매 관계. 남들은 모름)
- 마신이 된 것은 **자의가 아니다**: 세상의 균형 때문에, 자매가 성녀로 선택받으면서 마신이 되었다 (강제적, 세상의 섭리)
- 그 뒤 **마기에 물들어** 악을 추구하고 악한 감정에 물들었다 → 이때부터는 자의. 사람이 진짜 변한 것
- 겉모습: **진상이 밝혀지기 전까지는 남성형**으로 나온다. 인간이 아닌 크리처 같은 모습
- 컨셉: **동양 무협풍, 검은색이 메인 컬러** → 검사 주인공과 연결됨

### 😇 (과거) 성녀
- **마신의 동생** (자매 관계. 남들은 모름)
- **'마력'의 신에게 간택**받았다. 그래서 세상에서 마법을 가장 잘 다루는 사람이었다
- 성녀가 된 것도 **자의가 아니다** (세상의 섭리)
- 언니인 마신에게 슬픔과 동정심을 품고 있었다. 그래서 마신과 영웅들의 전쟁 때 **도저히 혈육을 죽일 수 없었다**

### ⚔️ 마신과 영웅들의 전쟁 때 일어난 일
1. 성녀가 갑자기 영웅들에게 부탁했다: "그녀는 내 언니이니 한 번만 말을 걸어 볼 기회를 달라. 내가 해결할 수 있다. 그녀에게는 인격이 남아 있을 것이다"
2. 영웅들에게는 이것이 **일종의 배신**처럼 느껴졌고, 갈등이 커졌다
3. 그때 성녀가 마신에게 **교감**을 시도했다
4. 악에 물든 마신은 성녀를 동생으로 보기는커녕, **성녀의 정신에 파고들어 '마력의 신'에게 닿는 길**을 찾아냈다
5. 그래서 **마력의 신이 죽었다** (원래 마력의 신은 절대적이라 마신이라도 어림없었다)
6. 그래서 성녀는 **영웅들에게 죽었다**
7. 아무도 전말을 모르니, 역사에는 **"성녀와 영웅들의 희생"**으로 기록되었다

### 🦸 대영웅 5인
- **원소를 대표하는 5인**. 마력의 신에게서 특정 원소를 특히 잘 다룰 수 있는 힘을 받았다

| 원소 | 대영웅 |
|---|---|
| 🔥 불 | 검사 |
| 💧 물 | 마법사 |
| 🌿 땅 | 궁수 |
| 🌑 어둠 | 도적 |
| ✨ 빛 | 직업 미정 |

### 현재 시점 ✅
- 봉인 후 **약 300년**
- 300년 동안 재건하느라 힘들었고, **지금은 안정되어 가는 중**
- 마법이 **한 번 사라졌었고**, 인류는 그 감각을 다시 익히는 중. 사람들이 다시 마법을 열심히 배우고 쓰고 있다
- 그래서 **마법학교(명문 아카데미)**가 중요한 시대

### 마법학교 ✅
- 명문 아카데미. 세 주인공은 그냥 이 학교의 학생이다 (특별한 입학 사연 없음)
- 학과: 검술과 / 마법학과 / 궁술과

## 3. 직업별 개인 스토리 ✅

### ⚔️ 검사
| 항목 | 내용 |
|---|---|
| 성격 | 진중하고 조용함. 조금 어둡고 과묵함 |
| 출신 | 평범한 가정, **쌍둥이 남매** |
| 성장 | 마을 이웃이던 검술 스승에게 배움. 검술이 적성이고 무척 좋아함 |
| 내면 | 어릴 때 폭력적인 충동을 종종 느꼈지만, 검술로 그 성격을 우회시키며 성숙해짐 |
| 비밀 | **마신의 하수인이자 가장 온전한 씨앗**. **본인은 모른다** (스토리의 큰 반전) |
| 마신과의 연결 | 마신은 동양 무협풍·검은색 메인 컬러 → 검사 주인공과 이어짐 |

- 캐릭터 생성 때 성별 대신 **쌍둥이 오빠 / 쌍둥이 여동생** 중 누구로 플레이할지 고른다
- 고르지 않은 쪽은 **NPC**로 등장: 늘 남매의 재능에 가려져 있었고, 가까이 있어서 가끔 보이는 그 성격이 신경 쓰인다
- **선택받지 못한 쪽의 운명** (2026-11-12): 사실 이쪽이 **다음 성자/성녀가 될 운명**이다. 아무도 모른다
  - 과거 이야기(자매인 성녀와 마신)의 **복선**: 한쪽은 마신의 씨앗, 한쪽은 다음 성자/성녀인 쌍둥이

### 🔮 마법사
| 항목 | 내용 |
|---|---|
| 성격 | 밝고 호기심 많음 |
| 출신 | 이곳저곳 여행하는 **떠돌이 학자 부부**의 하나뿐인 아이 |
| 재능 | 마법은 천재 수준. 학교의 관심을 한몸에 받으며 **수석 입학** |
| 비밀 | 마신이 죽였던 **'마력'의 일부가 환생**한 존재. 아무도 모른다 |

- 모험과 (나중에 끌리게 될) 마신의 이야기에 끌리는 건, **본능적으로 태어난 곳이자 죽은 곳으로 돌아가기 위해서**다

### 🏹 궁수
| 항목 | 내용 |
|---|---|
| 종족 | **엘프** (혼혈). 이 세계의 엘프는 신성한 정령 취급, 숨어 지내는 소수 |
| 출신 | 조금 가난하지만 화목한 인간 가정. 갓난아이 때 주워져 사랑으로 자람 |
| 표식 | 발견 당시 이미 엘프 부족 특유의 **문신**(인위적으로 새김)이 있었음 |
| 성격 | 무뚝뚝하고 차분함 (검사의 어둡고 과묵함과는 다름) |
| 비밀 | **대영웅 중 한 명의 먼 친척**의 아이 (혈통이 짙지는 않음) |
| 주제 | 정체성과 소속감 찾기, 방황. 메인 스토리와 깊이 얽히진 않지만, 언젠가 **자력으로 세계를 구하기 위해 용기를 낸다** |

### 세 주인공의 대비
| | 검사 | 마법사 | 궁수 |
|---|---|---|---|
| 마신과의 관계 | 마신의 씨앗 (마신 쪽) | 마신에게 죽은 마력 (피해자 쪽) | 마신을 봉인한 영웅의 먼 혈통 (봉인 쪽) |
| 본인이 비밀을 아는가 | 모름 (반전) | 모름 | 모름 (문신이 단서) |
| 성격 | 어둡고 과묵 | 밝고 호기심 | 무뚝뚝하고 차분 |

## 4. 검토 중
- **다른 직업 주인공의 NPC 등장**: 내가 고르지 않은 직업의 주인공들이 같은 학교 학생 NPC로 나온다. 유저도 같은 생각이지만, 스토리를 직업별로 따로 써야 해서 적용은 더 고민 중

## 5. 💡 Claude 제안 (미확정)
- **5원소 = 죽은 마력의 신의 조각**: 마력의 신이 죽으며 불·물·땅·빛·어둠으로 흩어졌고, 그래서 사람들은 원소로 쪼개진 마법만 쓸 수 있다. "마법이 한 번 사라졌다가 인류가 다시 익히는 중"이라는 설정과 이어진다
- ~~대영웅 5인 = 5원소~~ → 유저 확정 (2-1 대영웅 5인)
- **원소 몬스터**: 흩어진 원소가 뭉쳐 생긴 존재 (원소 슬라임 등)
